# Keyplayer 演奏教程

这篇教程将带你从零开始，用键盘学会演奏多首曲子。

## 安装

1. 从 [Releases](https://github.com/dolphinwesting248/Keyplayer/releases) 下载 `Keyplayer.zip` 并解压
2. 打开 Chrome，地址栏输入 `chrome://extensions/` 回车
3. 右上角开启「开发者模式」，点击「加载已解压的扩展程序」
4. 选择解压出的文件夹，安装完成后建议将扩展固定在工具栏

---

## 第一课 · 小星星 — 认识键盘

先来一首所有人都会的曲子。安装后默认是 **Silent** 模式，按 `` ` ``（Esc 下方）切换到 **Play** 模式。

三排字母键就是你的琴键：

```
第一排（白键）  Q W E R T Y U I O P
第二排（黑键）  A S D F G H J K L
第三排（低音）  Z X C V B N M
```

Q 是中央 C，向右依次是 D、E、F……现在来弹小星星：

```
C C G G A A G
Q Q T T Y Y T

F F E E D D C
R R E E W W Q
```

按 Q 两下、T 两下、Y 两下、T 一下——第一句就出来了。接着 R R E E W W Q，完成。

你应该注意到了：**正常打字会受到影响**——无法进行填表、输入等操作。这时就可以按 `` ` `` 切到 **Hybrid** 模式，在输入框里打字时不会触发音符，只有点击页面空白处后才恢复演奏。两种模式用 `` ` `` 随时切换。

---

## 第二课 · 欢乐颂 — 八度切换

欢乐颂的主旋律比小星星音域更宽，有些音超出了默认键盘范围。按 `[` 降低八度、`]` 升高八度，弹出面板上能看到当前偏移值。

```
E E F G  G F E D  C C D E  E D D
E E W T  T R E W  Q Q W E  E W W

E E F G  G F E D  C C D E  D C C
E E W T  T R E W  Q Q W E  W Q Q
```

先用默认八度弹前两句。如果觉得音太低，按 `]` 升高一个八度再试试——同一组按键，音高变了。

音域对照：键盘覆盖 C1 到 G#7，按 `[` `]` 可在三个八度间移动。弹高音旋律用高八度，弹低音和弦用低八度。

---

## 第三课 · 卡农 — 延音踏板

卡农的和弦进行需要一个音一个音地铺开，如果每个音都短促地断开，听起来会很干。这时候需要**延音踏板**。

按住 **Space** 不放，弹奏的音符在松开按键后仍会持续发声。括号 `( )` 表示按住 Space 弹完括号内所有音，到 `)` 释放。来试一段最简单的卡农低音：

```
( Q  T  Y  E  R  Q  R  T )
```

用左手按住 Space 不放，右手依次弹 Q、T、Y、E、R、Q、R、T。你会发现这些音各自持续，层层叠加——四个音同时响起的和声效果，就是踏板的力量。

---

## 第四课 · 月亮代表我的心 — 力度控制

这首歌需要轻柔地弹，偶尔加重表达情感。记号 `+` 表示按住 Shift 的同时弹这个音，力度加倍，声音更响亮。

```
Q  E  T  +Y  T  E  Q
```

先用正常力度弹 Q、E、T，到第四个音按住 Shift 再按 Y——这个音明显更响亮，情感一下子就出来了。实际演奏中，旋律高点加力度、伴奏音不加，就能做出层次感。

右下角浮动提示会显示累计力度值，方便确认当前是否处于力度加强状态。

---

## 第五课 · 换乐器 — 吉他、贝斯与风琴

钢琴很好，但有些曲子换了音色才出味道。弹出面板中可以看到当前乐器列表，自带 7 种音色：

| 乐器 | 特点 |
|------|------|
| 钢琴 | 多层采样，音域最宽 |
| 吉他 | 温暖的原声吉他 |
| 电吉他 | 清亮的电声 |
| 贝斯 | 低音专用 |
| 萨克斯 | 柔滑的管乐 |
| 风琴 | 教堂管风琴 |
| chip | 8-bit 方波合成器 |

快捷键：

| 按键 | 操作 |
|------|------|
| `1` ~ `9` | 直接选第 1 ~ 9 个乐器 |
| `;` | 循环切换下一个 |

点 **+** 可自由增删列表中的乐器，按 `1` 选钢琴、`2` 选吉他、`3` 选电吉他……前 9 个乐器都有数字快捷键。

练一个低音走向——按 `4` 切换到贝斯，弹：

```
C  G  A  F
Z  B  N  V
```

低沉的贝斯线和刚才的钢琴主旋律完全是两种感觉。

---

## 第六课 · 录音与导出

现在你已经能完整演奏曲子了。按 `'`（引号键）开始录音，弹奏你想录的内容，再按一次 `'` 停止。弹窗会提示导出为 JSON 文件 。

录音会自动裁剪首尾空白，不用担心开头结尾有多余的静默。

---

## 第七课 · 歌曲播放

别人写好的曲子也可以直接导入演奏。打开弹出面板，切换到 **Songs** 标签：

- 点击 **+ JSON** 导入 `.json` 歌曲文件
- 点击 **+ MIDI** 导入 `.mid` 文件
- 点击播放按钮开始自动演奏
- 再次点击可暂停，进度条随时可查看位置

暂停后再次播放从上次位置继续。同一首歌里不同音符可以指定不同乐器——

```json
{ "s": -20, "t": 0,   "d": 600, "i": "bass" },
{ "s": 0,   "t": 0,   "d": 600, "i": "guitar" },
{ "s": 7,   "t": 600, "d": 400, "i": "organ" }
```

贝斯铺底、吉他节奏、风琴旋律——一首歌三种音色，全自动切换。想自己写歌？参考 [song-guide-zh.md](./song-guide-zh.md)

## 第八课 · 混响

按 `\` 打开混响，再弹一遍之前学过的曲子——声音从干燥的房间搬进了音乐厅。混响模拟了 4 条延迟线 + 低通滤波器的空间反射，钢琴和风琴效果最明显。

弹出面板中可调节混响强度（0% ~ 100%），`\` 快捷键在开/关之间切换。

---

## 第九课 · 卡农 — 综合演奏

现在把你学到的所有技巧串起来，完整演奏一次帕赫贝尔的《卡农》。全程用钢琴音色，先按 `\` 打开混响。

**低音部**（用贝斯音色）：

卡农的低音是 8 个音循环重复。让每个音持续、层层叠加——踩下踏板：

```
( Z  B  N  V  X  Z  X  B )
```

左手按住 Space 不放，右手依次弹 Z、B、N、V、X、Z、X、B。八个音全部响起，这就是卡农的底色。

切回钢琴，低音继续用钢琴重复两遍，加入力度变化——每小节第一个音加重：

```
( +Z  B  N  V  +X  Z  X  B )
( +Z  B  N  V  +X  Z  X  B )
```

按住 Space 贯穿两遍，只在标记 `+` 的地方同时按住 Shift 加重低音落点。

**和弦部**（保持钢琴，Space 持续）：

在和弦进行上叠入旋律骨架。每三个音一组，第一组正常、第二组末尾加重：

```
Q W E   W E R   E R T   R T Y
Q W E   W E +R   E R T   R T +Y
```

保持踏板踩住，每组音之间稍有停顿。第三四句往上走，情绪推进：

```
T Y U   Y U I   U I O   I O P
T Y +U   Y U +I   U I O   I O +P
```

到高音区仍然踩住踏板，最后四个和弦用重音收束。

**收尾**（松开 Space）：

```
Q   E   T   +Y
```

全部松开，只听最后一个和弦在混响中渐渐消散。

---

整首曲子用到了你学过的全部技巧：八度选择、踏板叠加、力度分层、乐器切换、混响润色。打开录音（按 `'`），完整过一遍，导出你的第一份卡农录音吧。

## 附录 · 乐谱记号

| 记号 | 含义 |
|------|------|
| `Q` | 直接按下按键 Q |
| `( Q  W  E )` | 按住 Space 弹完括号内所有音，`)` 处松开 |
| `+Q` | 按住 Shift 的同时按 Q，力度加倍 |
| `( +Q  W )` | 同时按住 Space 和 Shift，弹 Q（重音）；松开 Shift 弹 W；`)` 处松开 Space |

|------|------|

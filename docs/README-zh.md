# Keyplayer

将键盘变成乐器的浏览器扩展，打字之外，让键盘替你发出声音。

## 安装

1. 在 [Releases](https://github.com/dolphinwesting248/Keyplayer/release)中下载`Keyplayer.zip`并解压
2. 打开 Chrome，进入 `chrome://extensions/`
3. 开启「开发者模式」，点击「加载已解压的扩展程序」
4. 选择解压出的目录

## 演奏

三排字母键覆盖 C1 到 G#7，`[` `]` 切换八度：

| 排 | 按键 | 音域 |
|----|------|------|
| 第一排（白键） | Q W E R T Y U I O P | C4 ~ E5 |
| 第二排（黑键） | A S D F G H J K L | C#4 ~ G#5 |
| 第三排（低八度） | Z X C V B N M | C3 ~ B3 |

## 模式

| 模式 | 说明 |
|------|------|
| **Play** | 全键盘演奏，所有按键触发音符 |
| **Hybrid** | 自动识别输入框，打字时不触发，空白处照弹不误 |
| **Silent** | 禁用键盘演奏，仅保留后台功能 |

## 快捷键

| 按键 | 功能 |
|------|------|
| `` ` `` | 切换模式 |
| `-` `=` | 降低 / 提高音量 |
| `[` `]` | 降低 / 升高八度 |
| `\` | 切换混响 |
| `;` | 循环切换乐器 |
| `1` ~ `9` | 直接选择列表中第 1 ~ 9 个乐器 |
| `'` | 开始 / 停止录音 |
| Space | 延音踏板 |
| Shift | 力度加强 |

## 乐器

内置 多 种乐器音色，可自由组合管理：

- **钢琴** — 7 层采样，覆盖 C1 ~ C7
- **吉他** — 5 层采样，覆盖 C2 ~ C6
- **电吉他** — 3 层采样，覆盖 C2 ~ C5
- **贝斯** — 2 层采样，覆盖 C2 ~ C3
- **萨克斯** — 4 层采样，覆盖 C3 ~ C6
- **风琴** — 5 层采样，覆盖 C2 ~ C6
- **芯片音色** — 合成器方波，无需加载采样

在弹出面板中可自由增删乐器，`1` ~ `9` 数字键对应列表前 9 个。

## 歌曲播放

支持导入 JSON 和 MIDI 歌曲文件进行自动演奏。

### JSON 格式

```json
{
  "title": "歌曲",
  "bpm": 120,
  "octave": 0,
  "notes": [
    { "s": 0, "t": 0,    "d": 500 },
    { "s": 4, "t": 500,  "d": 500 },
    { "s": 7, "t": 1000, "d": 500 }
  ]
}
```

> 详见   [song-guide-zh.md](./song-guide-zh.md)

### 逐音符乐器

每个音符可通过 `i` 字段单独指定乐器，同一首歌里不同音区可分配不同音色：

```json
{ "s": -20, "t": 0, "d": 500, "i": "bass" },
{ "s": 0,   "t": 0, "d": 500, "i": "guitar" }
```

## 录音

按下 `'` 开始录音，再按一次停止。录音自动裁剪首尾空白，可将录音导出为 MIDI 文件保存。

## 混响

内置反馈延迟网络（FDN）混响效果，4 条延迟线 + 低通滤波器，按 `\` 开关。

## 开发

```bash
npm install        # 安装依赖
npm run dev        # 开发模式（热更新）
npm run build      # 生产构建
npm run package    # 打包为 .zip
```

### 技术栈

- [Plasmo](https://www.plasmo.com/) — 浏览器扩展框架
- React 19 + TypeScript
- Web Audio API — 音频引擎

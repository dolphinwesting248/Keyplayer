# 歌曲编写指南

## 文件格式

歌曲使用 JSON 格式：

```json
{
  "title": "歌曲",
  "bpm": 120,
  "octave": 0,
  "notes": [
    { "k": "Q", "t": 0,    "d": 500 },
    { "k": "E", "t": 500,  "d": 500 },
    { "k": "T", "t": 1000, "d": 500 }
  ]
}
```

## 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `title` | string | 歌名，播放时在右下角浮动提示中显示 |
| `bpm` | number | 曲速（拍/分钟），仅供参考，不影响实际播放 |
| `octave` | number | 全局八度偏移（-3 ~ +3），每 ±1 所有音符升降 12 个半音 |
| `notes` | array | 音符数组 |

### 音符对象

| 字段 | 说明 |
|------|------|
| `k` | 按键名称，见下方对照表。也支持 `s`（半音偏移）作为替代 |
| `o` | *(可选)* 单音符八度偏移（-5 ~ +5） |
| `t` | 开始时间（毫秒），从乐曲起点起算 |
| `d` | 持续时长（毫秒），音符在 `t + d` 时刻停止 |
| `i` | *(可选)* 该音符使用的乐器 ID。可选值：`piano`、`chip`、`guitar`、`eguitar`、`bass`、`sax`、`organ`。未指定时使用默认乐器 |

### 两种音符格式

支持两种格式指定音高。

**格式一：`k` + `o`（推荐）**

```json
{ "k": "Q", "t": 0, "d": 500 }            // C4
{ "k": "Q", "o": 1, "t": 500, "d": 500 }  // C5（高八度）
{ "k": "Z", "o": -1, "t": 1000, "d": 500 } // C2（低八度）
```

- `k`：26 个字母键之一（Q/P/Z/M 等）
- `o`：可选，单音符八度偏移。`k` + `o` 覆盖全钢琴音域

**格式二：`s`（兼容）**

```json
{ "s": 0,  "t": 0, "d": 500 }  // C4
{ "s": 12, "t": 0, "d": 500 }  // C5
{ "s": -24,"t": 0, "d": 500 }  // C2
```

- `s`：相对 C4 的半音偏移
- 导入时如果 `k` 和 `s` 同时存在，优先使用 `s`

## 编写技巧

### 拍子

120 BPM = 每拍 500ms。按倍数推算：

| 音符 | 时长 |
|------|------|
| 四分音符 | 500ms |
| 八分音符 | 250ms |
| 二分音符 | 1000ms |
| 全音符 | 2000ms |

每个音符的 `t` 值是其前面所有音符时长的累加。例如四分音符序列：

```json
{ "k": "Q", "t": 0,    "d": 500 },
{ "k": "W", "t": 500,  "d": 500 },
{ "k": "E", "t": 1000, "d": 500 }
```

### 和弦

多个音符设置相同的 `t` 值即可同时发声：

```json
{ "k": "Q", "t": 1000, "d": 800 },
{ "k": "E", "t": 1000, "d": 800 },
{ "k": "T", "t": 1000, "d": 800 }
```

### 常用和弦公式

以根音半音值 `s` 为基准：

| 和弦类型 | 半音组合 |
|----------|----------|
| 大三和弦 | `s`, `s+4`, `s+7` |
| 小三和弦 | `s`, `s+3`, `s+7` |
| 挂四和弦 | `s`, `s+5`, `s+7` |
| 大七和弦 | `s`, `s+4`, `s+7`, `s+11` |
| 小七和弦 | `s`, `s+3`, `s+7`, `s+10` |

例如 C 大三和弦：`s=0` → 音符 `{0, 4, 7}` 即 C-E-G。

### 常用和弦进行

- **卡农进行：** `0 → 9 → 11 → 6 → 7 → 0 → 7 → 9`
- **I-V-vi-IV：** `0 → 7 → 9 → 5`
- **12 小节布鲁斯（C 调）：** `0 (4小节) → 5 (2小节) → 0 (2小节) → 7 (1小节) → 5 (1小节) → 0 (2小节)`

### 八度

用 `octave` 字段整体移调，无需逐个修改音符：

- `"octave": -1` → 全部降低一个八度
- `"octave": 1`  → 全部升高一个八度

### 休止

在两段音符之间留出时间空隙即可：

```json
{ "k": "Q", "t": 0,    "d": 500 },
{ "k": "W", "t": 800,  "d": 500 }
```

`t + d = 500`，下一个 `t = 800`，中间有 300ms 的静默。

### 注意事项

- 每个音符自动分配 ID（`song_0`, `song_1`...），同一 ID 的音符不能时间重叠
- 和弦通过在 `notes` 中放置多个相同 `t` 的音符实现，不需要手动管理 ID
- `i` 字段可为每个音符单独指定乐器，播放器会在切换乐器前自动加载所需采样

## 完整示例

```json
{
  "title": "C大调琶音",
  "bpm": 100,
  "octave": 0,
  "notes": [
    { "k": "Q",  "t": 0,    "d": 600 },
    { "k": "E",  "t": 600,  "d": 600 },
    { "k": "T",  "t": 1200, "d": 600 },
    { "k": "I", "t": 1800, "d": 1200 },
    { "k": "Q",  "t": 0,    "d": 600 },
    { "k": "E",  "t": 0,    "d": 600 },
    { "k": "T",  "t": 0,    "d": 600 }
  ]
}
```

前四个音符是上行琶音（C → E → G → C），后三个同时起奏是和弦收尾。
